# Flexible import examples

All records are fictional. Verified through the public website on 6 November 2026.

- `multi-sheet-excel-dates.xlsx`: choose **Crew duties**, map Employee to Crew ID, Full name to Crew name, Role to Crew role, Duty to Duty ID, Start to Duty start, End to Duty end, and Expiry to Certification expiry. Choose **America/New_York**. Excel 06:00–14:00 becomes 11:00–19:00 UTC. Expected: one duty, zero findings under initial rules. The Instructions sheet is ignored.
- `601-duties.csv`: upload and run directly. Expected: 601 duties, 601 fictional crew and zero findings under initial rules.

Both examples lack preceding-rest evidence for each crew member's first duty. Zero findings is not a full compliance certification. These examples verify selected behavior; they do not establish production capacity.
